ClaudeVN maintains a multi-user atmosphere. This is a deliberate choice with future potential.

**Why:** The collaborative/multi-user model is differentiated and has future value the user doesn't want to lose.

**How to apply:** Don't simplify away multi-user features (presence, auth, user management, shared project views). Design new v2.0 UI with multiple concurrent users in mind — decomposition review should support collaborative input, verification results visible to team.
