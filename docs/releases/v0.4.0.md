# v0.4.0 — Control Center

**Release Date:** 2026-03-07

## Highlights

This release introduces the **Control Center** — a conversation-first collaborative workspace that replaces the traditional dashboard. Instead of navigating between forms and tables, you now interact with ClaudeVN through a unified chat interface with real-time observability panels.

## Control Center

- **Conversation workspace** — Full-bleed chat as the primary dashboard experience (#188)
- **Adaptive chat rail** — Left-side minimal chat persists on non-dashboard pages (#189)
- **Live summary cards** — Real-time project pulse with backlog, execution, and timing panels (#190)
- **3-column layout** — Rich observability panels alongside conversation (#226, #228, #229)
- **Notification indicators** — Cross-block notification dots highlight activity across panels (#229)
- **Smooth transitions** — Animated chat panel transitions between control center and sidebar (#210)

## Conversational Interaction

- **Chat-first input** — Natural language commands with slash-command support and promote-to-directive action (#194)
- **System messages** — Automated system-initiated messages in conversation timeline via event bridge (#197)
- **Inline action cards** — Attention alerts, suggestions, and unified card styling in the timeline (#198)
- **Conflict detection** — Multi-user conflict detection for contradicting directives (#199)
- **Onboarding flow** — Conversation-first onboarding for new users and empty projects (#201)

## Multi-User Collaboration

- **User identity** — Pluggable auth providers with local file-based and AWS Cognito modes (#217)
- **User presence** — Real-time online status, heartbeat, and activity indicators (#193, #220)
- **Team presence** — Global team presence tracking with 3-day retention (#220)
- **User avatars** — Deterministic color avatars and identity indicators across the UI (#175)
- **User attribution** — Created-by/modified-by tracking on projects, issues, directives, and goals (#176, #202)
- **WebSocket sync** — Real-time multi-user conversation broadcast (#192)
- **Server-persisted conversation** — Conversations stored server-side with user attribution (#191)

## Observability and Metrics

- **Hardware resource metrics** — CPU, memory, and disk usage displayed in control center and network details (#225)
- **Aggregate health API** — Hardware resources exposed via the health endpoint (#207)
- **Timing insights** — Aggregate timing statistics in the timing observable block (#228)
- **Backlog panel** — Issue mini-list with two-line layout and priority badges (#226)

## UI and Design

- **Design system consolidation** — Eliminated hardcoded styles across all pages with CSS variable tokens (#187)
- **Unified page layout** — Consistent header, spacing, and scroll behavior (#196)
- **Theme switching** — Light/dark theme support with per-user preferences (#223)
- **Responsive layout** — Mobile bottom nav, tablet breakpoints, and adaptive grid (#200)

## Infrastructure

- **Request-scoped user context** — Middleware for user identity on all API endpoints (#195)
- **Audit trail** — Full mutation audit trail with user attribution (#202)
- **Configurable display hostname** — Custom hostname for repo URLs (#206)
